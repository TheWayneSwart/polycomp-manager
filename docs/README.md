# Protocol documentation

The only public description of PolyComp's GTXC serial protocol is a 2008 snapshot of the vendor's
website, preserved by the Internet Archive:

https://web.archive.org/web/20080218105448/http://www.polycomp.co.za/protocol.html

It is PolyComp's copyright, so it is not redistributed here. A local copy may be kept in this
directory as `gtxc-protocol-2008-archive.html` (git-ignored) for offline reading. Everything the
project learned from it, and the corrections found by testing against a real sign and reading the
controller firmware, is written up in [`../CLAUDE.md`](../CLAUDE.md).
